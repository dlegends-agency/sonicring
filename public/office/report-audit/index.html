Baseline Issues & Recommendations

Findings from the audit of the /office/ pages and what shipped since. Items below are fixed unless marked Open or Review.

Technical Infrastructure

Pages
Homepage is static public/index.html; its CSS/JS, legal pages and this report live in public/office/. /office/ redirects to /. The React app moved to app.html (old funnel homepage now at /funnel)
Hosting
Cloudflare Pages serves static files first; _redirects sends every other route to /app.html (the React app). A Vite plugin mirrors this for npm run dev and vite preview
3D scene
three.js r170 (minified) via jsDelivr import map · WebGL · selective bloom post-processing
Animations
Vanilla JS (features.js) + CSS keyframes · respects reduced-motion settings
Fonts
Geist + Geist Mono via Google Fonts
Sitemap
public/sitemap.xml (3 office URLs added)
robots.txt
public/robots.txt (allows /office/)
Favicon
/favicon.ico, /favicon-16x16.png, /favicon-32x32.png, /icon-192.png, /apple-touch-icon.png (shared with the React app)
OG image
/images/og-image.png (1200×630, shared with the main site)
Analytics
GA4 + Facebook Pixel via /office/tracking.js — 2/3 configured (Google Ads not set)
Forms
Early-access waitlist (work email, phone, business name, business type, plan interest): client-side validation only

"Book Your Free Strategy Session" and "Reserve My Spot" (waitlist)
